FOC Mathematics: From Three-Phase Sine Waves to SVPWM

Mathematical companion to the HIL FOC project using MATLAB/Simulink and STM32G431.

What this document covers

This page follows the signal path used in the project: simulated three-phase motor quantities → electrical angle → Clarke transform → Park transform → id/iq current control → PI controllers and motor-dependent decoupling → inverse Park transform → Vα/Vβ → space-vector representation → SVPWM timing → inverter duty cycles.

The uploaded project specifically documents Simulink generating phase-current samples and electrical angle, sending them to the STM32G431, performing Clarke/Park transformations, returning id/iq, then applying closed-loop control and inverse Park to obtain Vα/Vβ. The project identifies the SVPWM timing/duty calculation as the next reconstruction step from these outputs.

1. Signal chain — explained in words

The process begins in MATLAB/Simulink, where the virtual motor and load model generate the three phase-current quantities and the electrical rotor angle. In the HIL implementation, these values are converted to single-precision floating-point values, packed into a byte stream, and transmitted to the STM32G431 through UART.

The STM32 receives and reconstructs the current and angle values. It first applies the Clarke transformation to convert the three-phase abc quantities into the stationary two-axis αβ reference frame. It then applies the Park transformation, using the electrical rotor angle, to rotate the stationary frame into the synchronously rotating dq frame. This produces id and iq.

The calculated id and iq values are sent back to Simulink. Simulink uses them as feedback for the closed-loop current/torque control. The difference between the requested and measured currents becomes the PI-controller error. The PI controllers generate voltage commands, and motor-dependent decoupling terms are added to compensate for the cross-coupling effects of the rotating reference frame.

The resulting Vd and Vq commands are converted back into stationary-frame components by the inverse Park transformation. The final Vα and Vβ values represent the requested stator voltage vector. These two quantities are then sufficient to reconstruct the vector magnitude and angle and, subsequently, the SVPWM switching times and inverter duty cycles.

This description follows the workflow documented in the supplied HIL project: Simulink generates the motor-side quantities, the STM32G431 performs Clarke/Park processing, the returned d-q currents are used for closed-loop control, and inverse Park produces Vα/Vβ. fileciteturn2file0L23-L35

2. Generating the three-phase waveforms

1

Balanced three-phase quantities

A balanced sinusoidal three-phase set can be written as:

ia(t) = Î sin(ωet + φ)
ib(t) = Î sin(ωet + φ − 2π/3)
ic(t) = Î sin(ωet + φ + 2π/3)

For a balanced system:

ia + ib + ic = 0

Mechanical speed → electrical speed

ωm = 2π · RPM / 60
ωe = p · ωm = 2πp·RPM/60
θe(t) = θe,0 + ∫ωe(t)dt

Here p is the number of pole pairs. If speed is constant:

θe(t) = θe,0 + ωet

Project operating point: 500 RPM

The model uses 500 RPM for the speed used to calculate electrical angular speed.

ωm = 2π(500)/60 = 52.360 rad/s
ωe = p(52.360) = 52.360p rad/s

The exact electrical speed therefore depends on the number of pole pairs p configured in the motor model. For example, if a seven-pole-pair motor were used, ωe would be 366.519 rad/s. This seven-pole-pair number is only an example here and should be replaced by the actual pole-pair value from the Simulink motor block if it differs.

The electrical angle is obtained by integrating ωe. In a constant-speed case, θe(t)=θe,0+ωet. The 30° angle used in the numerical Clarke/Park example below is a snapshot of the electrical angle at one instant; it is not a claim that the motor remains at 30°.

3. Clarke transformation — abc → αβ

The Clarke transform removes the redundant three-phase representation and produces a stationary two-axis representation.

To keep the mathematics readable in a normal browser, the Clarke transform is written as two scalar equations rather than as a matrix:

iα = (2/3)ia − (1/3)ib − (1/3)ic
iβ = (1/√3)(ib − ic)

For a balanced three-wire system where ia+ib+ic=0, these equations simplify to:

iα = ia
iβ = (ia + 2ib)/√3

Consistent worked example used throughout this page

To make every numerical step traceable, the same balanced three-phase sample is used from the phase currents through Clarke and Park. Take a current amplitude of 10 A and an electrical angle of 30°:

ia = 10sin30° = 5.000 A
ib = 10sin(30°−120°) = 10sin(−90°) = −10.000 A
ic = 10sin(30°+120°) = 10sin150° = 5.000 A
ia + ib + ic = 5−10+5 = 0

Applying Clarke:

iα = (2/3)(5) − (1/3)(−10) − (1/3)(5) = 5.000 A
iβ = (1/√3)(−10−5) = −8.660 A

Now apply Park using the same θe=30°:

id = 5cos30° + (−8.660)sin30° ≈ 0 A
iq = −5sin30° + (−8.660)cos30° ≈ −10.000 A

This is the expected result for this particular choice of phase angle: the current vector is aligned with the negative q-axis, so the d-axis component is approximately zero and the q-axis component carries the full 10 A magnitude.

4. Park transformation — αβ → dq

The Park transform rotates the stationary αβ frame by the electrical rotor angle θe. This turns sinusoidally varying quantities into approximately DC quantities in steady state.

id = iαcosθe + iβsinθe
iq = −iαsinθe + iβcosθe

Inverse Park transformation

Vα = Vdcosθe − Vqsinθe
Vβ = Vdsinθe + Vqcosθe

Continuing the numerical example into voltage-vector generation

The current example above deliberately produces id≈0 A and iq=−10 A. For the voltage and SVPWM stages, use a clearly stated illustrative controller output of Vd=2.000 V and Vq=8.000 V at the same θe=30°. These voltage values are illustrative calculation values, not claimed to be the measured PI gains or voltage outputs of the uploaded model.

Vα = 2cos30° − 8sin30° = 1.732 − 4.000 = −2.268 V
Vβ = 2sin30° + 8cos30° = 1.000 + 6.928 = 7.928 V
Vref = √[(−2.268)² + (7.928)²] ≈ 8.246 V

5. Current errors and PI controllers

The controller compares the requested and measured dq currents.

ed(t) = id,ref(t) − id(t)
eq(t) = iq,ref(t) − iq(t)

Continuous-time PI controller:

u(t) = Kpe(t) + Ki∫e(t)dt

Thus the uncoupled voltage commands are:

Vd,PI = Kpded + Kid∫eddt
Vq,PI = Kpqeq + Kiq∫eqdt

Discrete implementation

I[k] = I[k−1] + KiTse[k]
u[k] = Kpe[k] + I[k]

An anti-windup limiter is normally required when the voltage command reaches the available DC-bus voltage.

6. Motor-dependent decoupling

For a PMSM dq model, cross-coupling terms arise because the rotating reference frame is itself moving.

Vd = Vd,PI − ωeLqiq
Vq = Vq,PI + ωe(Ldid + ψf)

where Ld and Lq are dq inductances and ψf is permanent-magnet flux linkage.

Project-specific note: your report says the decoupling terms are dependent on the motor construction and that the simulation uses the characteristics of the Blue Robotics T200 thruster. Therefore the exact parameter values and sign convention must come from your Simulink motor model; they should not be assumed from the generic equations above.

7. From Vd/Vq to Vα/Vβ

After PI correction and decoupling, the inverse Park transform produces the stationary-frame voltage vector:

Vα = Vdcosθe − Vqsinθe
Vβ = Vdsinθe + Vqcosθe

This is the important hand-off point for SVPWM.

Voltage-vector magnitude

Vref = √(Vα² + Vβ²)

Voltage-vector angle

θ = atan2(Vβ, Vα)

Normalize the angle into 0 ≤ θ < 2π if needed.

Worked example continuing the calculation above:
Vα = −2.268 V,   Vβ = 7.928 V
Vref = √[(−2.268)² + (7.928)²] ≈ 8.246 V
θ = atan2(7.928,−2.268) ≈ 105.96°

Because 105.96° lies between 60° and 120°, the vector is in Sector 2.

8. SVPWM concept

A two-level three-phase inverter has eight switching states:

StateSwitching vectorDescription
000V0Zero vector
100V1Active vector
110V2Active vector
010V3Active vector
011V4Active vector
001V5Active vector
101V6Active vector
111V7Zero vector

The reference vector is synthesized during one PWM period Ts using the two adjacent active vectors and the zero vector.

Ts = T1 + T2 + T0
T0 = Ts − T1 − T2

9. Sector calculation

Each sector spans 60°. For θ in [0, 2π):

Sector = floor(θ/(π/3)) + 1

For the local angle inside the selected sector:

θs = θ − (Sector−1)π/3
For the voltage-vector example above, Vα is negative and Vβ is positive, so:
θ = atan2(7.928,−2.268) ≈ 105.96°
Sector = floor(105.96/60) + 1 = 2
θs = 105.96° − 60° = 45.96°

10. SVPWM timing equations

For the common centered SVPWM formulation:

T1 = (√3 Ts Vref/Vdc) sin(π/3 − θs)
T2 = (√3 Ts Vref/Vdc) sin(θs)
T0 = Ts − T1 − T2

These equations are valid in the linear SVPWM region where the requested vector can be synthesized without overmodulation.

Worked SVPWM example

For an illustrative calculation, assume:

QuantityValue
Vα−2.268 V
Vβ7.928 V
Vref8.246 V
θ105.96°
Sector2
θs45.96°
Vdc24 V (illustrative)
Ts100 µs (illustrative)
T1 = (√3·100µs·8.246/24) sin(60°−45.96°) ≈ 14.44 µs
T2 = (√3·100µs·8.246/24) sin(45.96°) ≈ 42.78 µs
T0 = 100 − 8.60 − 43.05 ≈ 42.78 µs
The important point is that Vα and Vβ completely determine the reference vector. Once Vref, θ, sector and the local sector angle are known, the SVPWM timing can be calculated.

11. Convert T1/T2/T0 into duty cycles

A centered SVPWM implementation distributes half of T0 at the beginning and half at the end of the switching sequence.

For Sector 1, one common sequence is:

For a centered SVPWM implementation in Sector 1, the inverter applies the zero vector first, then the first adjacent active vector, then the second adjacent active vector, reaches the opposite zero vector at the center of the PWM period, and then follows the sequence in reverse. This symmetric sequence reduces switching asymmetry and is one common implementation of SVPWM.

The phase-on times for Sector 1 can be written:

Ta = (Ts + T1 + T2)/2
Tb = (Ts + T1 − T2)/2
Tc = T0/2

Then:

Da = Ta/Ts
Db = Tb/Ts
Dc = Tc/Ts

For Sectors 2–6, the same timing values are mapped to the appropriate phase order according to the active-vector sequence.

Implementation warning: there are several equivalent SVPWM duty-cycle formulations. The exact phase mapping, timer polarity, center-aligned mode and sector table must match the PWM implementation used by the inverter timer. The equations here describe the standard centered-SVPWM approach, not a claim about the exact timer implementation in this project.

12. Optional equivalent inverse-Clarke calculation

Once Vα and Vβ are known, the corresponding balanced phase-voltage references can also be reconstructed:

Va = Vα
Vb = −Vα/2 + (√3/2)Vβ
Vc = −Vα/2 − (√3/2)Vβ

For the illustrative Vα/Vβ example:

Va = −2.268 V
Vb ≈ 8.999 V
Vc ≈ −6.731 V
The three reconstructed phase references satisfy:
Va + Vb + Vc ≈ 0

SVPWM then adds the appropriate common-mode/zero-vector timing through its switching sequence rather than simply treating these as three independent sinusoidal PWM commands.

14. How this maps to the HIL project

The uploaded project reports that Simulink generates the phase-current samples and electrical angle, serializes the variables as single-precision values and sends them to the STM32G4 over UART. The STM32G431 reconstructs the variables and performs Clarke and Park transformations, producing id and iq. These are returned to Simulink for closed-loop control.

The project then applies PI control, torque/speed control and motor-dependent decoupling before the inverse Park transformation produces Vα and Vβ. The report identifies these two quantities as the synthesized stationary-frame stator voltage vector and explains that SVPWM timing and duty cycles can be reconstructed from them.

What has actually been validated

  • Simulated current and electrical-angle generation.
  • UART exchange between Simulink and STM32.
  • Embedded Clarke and Park transformations.
  • id/iq extraction and monitoring.
  • PI current-control tuning and decoupling response.
  • Inverse-Park Vα/Vβ behavior.

The physical gate-driver/inverter and physical-motor validation are described as future development in the project material.

15. Important convention notes

  • FOC equations depend on the sign convention chosen for q-axis direction and electrical angle.
  • Clarke transforms have amplitude-invariant and power-invariant conventions; numerical scaling changes between them.
  • The decoupling equations shown are the standard PMSM form. Use the exact motor equations/parameters from the Simulink model for this project.
  • SVPWM duty-cycle tables differ in presentation even when they synthesize the same reference vector.
  • For actual STM32 timer implementation, also account for dead time, PWM polarity, center-aligned counting and timer resolution.
